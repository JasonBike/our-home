# 原稿分析与新计划口径

核对日期：2026-09-22。用户已确认：上海首套二手房，400 万仅为房屋成交价；可用现金仍在商量；收入可填；生活支出暂不展开。房屋面积不能由总价推导。

## 先确定这张表到底在算什么

原稿把现金需求、消费和资产放在一起说“总共花多少钱”，容易误解。

- 首付换成房屋权益，不属于纯消费。
- 备用金是预留资金，尚未花出，不应再在付款表支出一次。
- 家具家电有使用价值，但不能当作可以随时拿来还贷的现金。
- 彩礼需要先确认支付方、收款方、是否转回小家和到账时间。即使最后留在小家，也可能先形成付款需求。
- 公积金贷款本金、未来利息不属于一次性现金预算；月供单独看。

因此页面分别展示「一次性预算」「双方先行准备」「月供」「一次性付款时间表」。不计算尚未讨论的生活支出，也不把月供后的收入余量叫作可储蓄金额。

## 原稿的数值与逻辑修正

| 原稿问题 | 新版处理 |
| --- | --- |
| 结婚各项最低额合计并非 17 万 | 逐项为 16.8～35 万；原稿买房 184.3 + 装修 42 时，总范围为 243.1～261.3 万 |
| 首付与税费写成 172 万 | 160 + 12.3 = 172.3 万，按实际值算 |
| 默认分摊男方 135.2、女方 115.2，展示相加偏差 | 默认实际为 135.15 / 115.15，合计 250.3 万；分摊显示两位小数 |
| 组合贷和纯公积金现金需求用了低档结婚预算，未与分摊同步 | 两个方案统一采用当前预算，默认 250.3 / 150.3 万 |
| 房价降 20 万时把首付减少算成 8 万 | 固定 240 万公积金贷款时，首付由 160 变 140 万，减少 20 万；若贷款额变动需重算 |
| 固定提前还款表与计算器可能不一致 | 所有提前还款数据按当前本金、利率、年限和金额逐月计算 |
| 零利率提前还款出现除零，期限超出后出现负剩余年限 | 明确零利率和期满边界，剩余期限不会负数 |
| 先把税收减免、低价房、婚礼低档和装修节省一起累加 | 不保留“最多省 67.5 万”的统一结论；每项必须对同一基准、满足对应条件，避免重复计算 |
| 冲还贷被描述为额外削减本金 | 按月抵扣视为月供的支付来源，不再重复计算提前还本金 |
| 把历史投资收益与贷款利率简单比较，直接得出必须提前还款 | 移除无条件结论；保留省息测算、流动性及资金用途提醒 |

## 400 万首套的交易费，为什么不能直接写死 12.3 万

### 契税取决于面积与税务认定

家庭唯一住房，建筑面积不超过 140㎡：不含增值税成交价 ×1%；超过 140㎡：×1.5%。若房源满二，免增值税，则 400 万对应契税 4 万 / 6 万。此处“家庭唯一住房”是税务口径，不应仅凭贷款首套认定代替。

来源：[上海税务局：个人购买家庭唯一住房](https://shanghai.chinatax.gov.cn/xwdt/ztzl/grsx/fwjy/grfclsx/202411/t474229.html)。

### 卖方税费不默认转嫁给买方

个人出售持有不足 2 年住房，增值税按含税销售额 ÷1.03×3%计算；满二免征。400 万含税计税成交价对应增值税约 11.6505 万。附加以增值税为基数，市区按城建税 7%＋教育附加 3%＋地方教育附加 2%，再按现行减半优惠，组合为增值税的 6%；对应约 0.6990 万，合计约 12.3495 万。页面将附加比例开放修改。

是否额外由买方承担，需结合合同。若报的是卖方净到手价，先明确合同价与税基；不能把净价直接当含税成交价。计算器不处理税费承担导致的合同价重定或税务调增。

来源：[上海税务局：不足 2 年住房](https://shanghai.chinatax.gov.cn/xwdt/ztzl/grsx/fwjy/csfclsx/202411/t474236.html)、[2026 年起住房增值税政策](https://shanghai.chinatax.gov.cn/zzzb/zcwj/202601/t478899.html)。

### 个税不总是 1%

满五且家庭唯一住房符合条件可免个税。其他情况下通常按扣除原值、税费及合理费用后的所得 ×20%；仅符合税务核定条件时才按转让收入 1%核定。继承、受赠等特殊取得方式另核，不能直接套 1%。原值资料不明时，页面不编造据实税额，要求填入已核定金额。

来源：[上海税务局：出售购入超过 2 年住房](https://shanghai.chinatax.gov.cn/xwdt/ztzl/grsx/fwjy/csfclsx/202411/t474237.html)。

### 非税费用需要真实报价

中介费没有页面可以替你确认的统一费率，1%只是示例，按买方实际承担比例填写。住宅转移登记通常 80 元/件；抵押登记由抵押权人缴纳，不能把所有登记费用直接加给购房人。评估、额外证书、专项委托等按实际发生额计入。

来源：[上海不动产登记收费标准](https://ghzyj.sh.gov.cn/ywlc/20200324/0032-827031.html)、[关于规范房地产经纪服务的意见](https://www.samr.gov.cn/zt/ndzt/2022n/scjgzjlswjjylzzcjchjxzc/zcwj/art/2023/art_f3f4bb43abda4338986166cc6a78f7a4.html)。

**一个条件齐全的例子**：400 万、面积≤140㎡、满五唯一、买方中介费假设1%、转移登记80元、无其他费用，则买方交易费用为 4 + 4 + 0.008 = **8.008 万**。这不是所有400万房源的统一费用；页面默认仍保留原稿12.3万，用户确认情景并应用后才替换。

## 贷款前提可能比装修更影响现金

2026-02-26起上海首套家庭公积金基本最高额度为200万，符合补充公积金条件可增加最高40万。240万不是所有家庭都能批到。实际还受缴存、余额、还款能力等约束。

400万房价、不增加商贷时，从240万降到200万贷款，需要额外40万首付；这比把家具预算节省几万对现金安排的影响更大。因此先核额度，再谈“要攒多少”。

30年、240万、2.6%等额本息，月供约9608元。页面仍用原稿2.6%作为可修改假设；官方利率通知对首套5年及以下是2.1%、5年以上2.6%，调整年限后应同步确认适用利率。商业利率3.1%也是试算假设，不代表银行报价。

来源：[上海公积金2026政策](https://www.shanghai.gov.cn/xbhygq/20260228/87e93e4c373c4bfe81af5557a77d2e70.html)、[公积金利率通知](https://www.shzfgjj.cn/html/newxxgk/zcwj/gjjgwh/albpl/dk/227927.html)。

## 装修和结婚的漏项，比再加一个总备用数更值得核对

- 装修报价：全包、半包分别包含什么；拆旧、清运、门窗、柜体、设计监理、成品保护、灯具窗帘、网络、保洁是否已计入。
- 硬装柜体与家具预算有没有重复；家具家电分批买时，哪些是入住前必需。
- 过渡租房、押金和搬家费用是否包含；月度模拟把这部分在入住月汇总，真实预付租金可能更早，不能凭汇总时间表安排实际转账。
- 结婚虽不办婚礼，仍要核家长交通住宿、衣服化妆、摄影套餐外费用和宴席附加；三金中的戒指与婚戒是否重复。
- 定金、装修预付款、摄影订金的到账顺序。金额相同，付款提前两个月会改变所需初始现金。

页面给购房、装修、结婚各加一个补充项目入口，暂为0并明确尚未报价；不自动叠加一套虚构费用。

## 暂缓计算的范围

按用户本轮要求，不展开每月生活支出、年度固定支出和生活应急金。房贷页的到手收入只用于月供占比和还贷后收入余量；公积金冲还贷金额不能从税后收入直接推导，需要填写公积金账户实际月入账额。公积金抵扣中断情景只展示额外月供现金需求，不据此断言收入安全。

一次性付款表不把未来工资直接列为可用资金，不扣月供和生活消费；这是专项资金时间表，不能冒充未来真实银行账户余额。填完现金前不显示虚假的“已充足”，也不替用户估计家人支持。
