# 我们的家

两个人的买房、装修、结婚预算。纯静态 HTML / CSS / JavaScript，没有后端、数据库、构建步骤、CDN 或部署脚本。

## 文件

- `index.html`：入口，Nginx 直接托管。
- `assets/`：样式、计算逻辑、页面交互、本地 SVG 插画。
- `reference/original.html`：桌面原稿，仅备查，不参与计算。
- `docs/预算分析.md`：原稿问题、预算口径、政策来源与未知项。
- `tests/model.test.mjs`：计算模型测试。

发布只需要 `index.html` 和完整的 `assets/` 目录，保持相对位置。资源使用相对路径，导航使用 hash，可放在站点根目录或子目录。通过 HTTP(S) 访问；ES modules 不适合直接双击 `file://` 预览。

## 页面内容

1. **计划总览**：现金预算、拿钥匙前付款、月供、资金构成和安家步骤。
2. **预算与分摊**：逐项预算、上海首套税费情景、两人出资比例。
3. **房贷小算盘**：公积金/组合贷、到手收入与月供占比、提前还款。
4. **现金与底气**：现有现金、家庭支持、彩礼回流与 12 个月一次性付款安排。
5. **安家备忘录**：实际条件核对、漏项清单与官方参考。

首套、400 万成交价是用户已确认的条件。现金、双方收入、面积、卖方住房情况均不编造值；生活支出本轮不计算。初始 12.3 万综合交易费保留原稿估算，选择完整税费情景并点击应用后替换，之后随房价联动；手动修改交易费会取消联动。

## 数据

预算自动保存在当前浏览器的 `localStorage`，键为 `our-home.plan.v1`。不会上传，也不会在不同浏览器、域名、设备间自动同步。使用「导出计划 / 导入」迁移 JSON；打印按钮输出完整计划。浏览器不允许本地存储时页面仍能计算，并提示导出备份。

新设备看到的是示例计划。`reference/`、`docs/`、测试文件无需发布。

## 计算与验证

- 一次性预算不含未来房贷本息。备用金计入资金需求，但在付款时间表中保留、不当作已支出。
- 定金包含在首付中，不重复计算；彩礼先支付、再按确认金额与月份计入回流。
- 未知现金不是 0。未来工资不冲减一次性资金缺口；收入只用于房贷页的月供比例与还贷后收入余量。
- 公积金抵扣只抵月供，不额外重复削减本金。提前还款仅测算公积金部分，按正常偿还所选年份最后一期后执行，逐月计算，末期按实际剩余本金计付。
- 模型支持零利率、无贷款、全额提前结清、超过贷款年限等边界。

本地模型测试（Node 自带测试工具，无 npm 依赖）：

```sh
npm test
```

页面已用本机 Chrome 检查桌面与手机布局、预算联动、缓存恢复、贷款切换、税费应用、导入导出及待办。月度安排是规划示例，付款与到账的月内先后仍需按真实合同确认。
